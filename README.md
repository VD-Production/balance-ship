# Корабль равновесия

Страница, стили, скрипты и ресурсы находятся в `balance-ship/`. GitHub Pages публикует корень ветки `main`, а корневой `index.html` перенаправляет посетителей в эту папку. [Открыть сайт](https://vd-prod.com/balance-ship/)

Откройте `balance-ship/index.html` в браузере. Для запуска через HTTP выполните команду из корня проекта.

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Страница будет доступна по адресу `http://127.0.0.1:8765/balance-ship/`. Шрифты, иллюстрации и видео хранятся в `balance-ship/assets/`.

Кадры показывают игровой мир по мотивам макетов. Тексты в юридических окнах помечены как черновики.

Форма «Обсудим внедрение» отправляет заявки через FormSubmit на `vadimovskiproduction@gmail.com`. Чтобы начать получать их, отправьте пробную заявку с опубликованного сайта и подтвердите адрес в письме от FormSubmit. [Инструкция FormSubmit](https://formsubmit.co/help)
